# AmperSubs Bot

Telegram бот для автоматизации заказов подписок с поддержкой API интеграции.

## 🚀 Возможности

- 💳 Автоматическое пополнение баланса через CryptoPay
- 🧾 Ручное пополнение баланса по реквизитам с подтверждением в админ-панели
- � Система заказов с отслеживанием статусов
- 📦 Каталог услуг с навигацией: Приложения → Услуги → Паки
- 💰 Гибкая оплата: баланс бота или прямое пополнение через криптобот
- 🔌 Интеграция с API smmway.ru для автоматического выполнения заказов
- 👤 Удобный профиль пользователя с кнопочной навигацией по истории заказов и пополнений
- 👑 Админ-панель с полным функционалом управления
- 📊 Статистика и аналитика
- 📩 Рассылка сообщений пользователям
- 🆘 Поддержка с возможностью указания нескольких контактов
- 🗄️ Автоматическое ежедневное резервное копирование базы данных
- 👥 Гибкая реферальная программа с начислением процента на баланс
- 🐛 DEBUG режим для тестирования без создания реальных заказов

## 📋 Требования

- Python 3.10+
- SQLite3
- Telegram Bot Token
- CryptoPay API Token

## 🔧 Установка

1. Клонируйте репозиторий:
```bash
git clone <repository_url>
cd ampersubs
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Настройте бота:
   - Откройте `main.py` и укажите ваш `API_TOKEN`
   - В `functions/payment.py` укажите ваш CryptoPay токен
   - В `main.py` укажите API ключ smmway.ru для интеграции
   - В `run.py` настройте `BACKUP_TIME` - время для ежедневного резервного копирования
   - Установите `DEBUG = True` в `main.py` для тестового режима (заказы создаются только в БД)

4. Запустите бота:
```bash
python run.py
```

## 📦 Каталог услуг

Бот поддерживает трехуровневую навигацию по каталогу:
1. **Приложения** - выбор приложения/сервиса

Каталог загружается из базы данных. Для синхронизации с API smmway.ru используйте:


## 💳 Оплата заказов

Бот поддерживает два способа оплаты:
- **Баланс бота** - если средств достаточно, заказ оплачивается сразу
- **Прямое пополнение** - если баланса недостаточно, создается счет на недостающую сумму через CryptoPay, после оплаты заказ создается автоматически

## 🔌 API для автоматизации

Модуль `functions/api.py` предоставляет класс `OrderAPI` для автоматического выполнения заказов.

### Пример использования:

```python
from functions.api import OrderAPI

async def main():
    api = OrderAPI()
    await api.init()
    
    # Создание заказа
    result = await api.create_order(
        tg_id=123456789,
        service="YouTube Premium",
        quantity=1
    )
    
    if result["success"]:
        order_id = result["order"]["id"]
        
        # Обработка заказа
        await api.process_order(order_id)
        
        # Завершение заказа
        await api.complete_order(order_id)
```

### Доступные методы API:

- `create_order(tg_id, service, quantity, payment_id)` - Создание заказа
- `update_order_status(order_id, new_status)` - Обновление статуса
- `get_order(order_id)` - Получение информации о заказе
- `get_user_orders(tg_id, status)` - Получение заказов пользователя
- `get_orders_by_status(status)` - Получение заказов по статусу
- `process_order(order_id)` - Автоматическая обработка заказа
- `complete_order(order_id)` - Завершение заказа

## 📊 Статусы заказов

- `new` - Новый заказ
- `processing` - В обработке
- `completed` - Завершен
- `cancelled` - Отменен
- `failed` - Ошибка

## 🐛 DEBUG режим

В файле `main.py` установлена переменная `DEBUG = True`. В этом режиме:
- Заказы создаются только в базе данных
- Запросы к API smmway.ru не отправляются
- Идеально для тестирования без создания реальных заказов

Для продакшена установите `DEBUG = False` и настройте API ключ smmway.ru.
